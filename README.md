# FactureFlash

Solution de relance d'impayés pour freelances créatifs (graphistes, designers, vidéastes) en Europe francophone.

## Description

FactureFlash est une application web qui aide les freelances créatifs à récupérer leurs impayés sans stress grâce à des modèles de relance spécifiques à leur métier et un système d'automatisation intelligent.

### Cible

Freelances créatifs (design, vidéo) en Europe francophone qui:
- Ont déjà subi des impayés
- Perdent du temps en relances manuelles
- Souhaitent maintenir une bonne relation client malgré les retards de paiement

### Promesse cash-first

FactureFlash permet aux freelances créatifs de:
1. Récupérer plus rapidement leurs impayés
2. Économiser le temps précieux passé en relances manuelles
3. Préserver leurs relations clients grâce à des messages au ton adapté

## Type de CTA

Capture de leads (early access) pour constituer une liste d'attente avant le lancement officiel.

## Comment lancer en local

1. Clonez ce dépôt
```bash
git clone https://github.com/delvalep-oss/facture-flash.git
```

2. Ouvrez le fichier `index.html` dans votre navigateur

3. Pour modifier le projet:
   - Éditez `index.html` pour la structure
   - Modifiez `style.css` pour l'apparence
   - Adaptez `script.js` pour les interactions

## Fonctionnalités de la landing page

- Calculateur d'impact financier des impayés (incluant le temps perdu en relances)
- Formulaire de capture d'email pour l'accès anticipé
- Présentation des bénéfices spécifiques aux freelances créatifs
- Offre early bird avec tarif préférentiel
